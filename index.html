SCHNELLSTART ANLEITUNG

Die Installation auf deinem Linux- oder Windows-Server ist denkbar einfach:

01

Repo Klonen

Klone das gewünschte Script direkt in deinen FiveM resources Ordner.

git clone <repo-url>
02

Config Anpassen

Öffne config.lua und passe Farben, Tastenbelegungen und Optionen an.

Config.Framework = 'qb'
03

server.cfg Eintragen

Trage den Ressourcennamen in deine Hauptkonfiguration ein.

ensure caspar_hud_v2
04

Server Starten

Starte deinen Server neu oder führe refresh und ensure in der Konsole aus.

refresh && ensure [caspar]
